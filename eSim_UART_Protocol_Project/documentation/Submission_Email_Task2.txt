1. PROPOSAL & CIRCUIT DETAILS
--------------------------------------------------------------------------------
• Project Title: Design, Mixed-Signal Circuit Modeling, and Verification of a 
  Noise-Tolerant UART Communication Transceiver Link using eSim
• Communication Protocol: Universal Asynchronous Receiver-Transmitter (UART) 8-E-1 
  (8 Data Bits, Even Parity, 1 Stop Bit, 16x Oversampling Clock Recovery)
• GitHub Repository: https://github.com/08Khushi11/Communication-Protocol-Modelling-and-Verification-using-esim
• System Architecture:
    - Transmitter (TX): RTL / Gate-level FSM with frame serializer & parity generator
    - Physical Channel: Distributed lossy RC transmission line (R=150 ohms, C=940 pF) 
      with coupled high-frequency EMI noise source (0.45V @ 400 kHz)
    - Receiver Front-End: Analog Schmitt Trigger comparator with 1.0V hysteresis window
      (V_TH+ = 3.0V, V_TH- = 2.0V) for noise rejection
    - Receiver (RX): Asynchronous 16x oversampled clock synchronizer, mid-bit sampler 
      (sample 8 of 16), SIPO shift register, and Parity/Framing error checkers

--------------------------------------------------------------------------------
2. EVALUATION CRITERIA COMPLIANCE SUMMARY
--------------------------------------------------------------------------------
• Successfully modelled communication protocol in eSim:
  Complete KiCad schematic (.kicad_sch), NgVeri Verilog RTL modules (uart_tx.v, 
  uart_rx.v, uart_top.v, uart_tb.v), and Ngspice mixed-signal netlist 
  (UART_MixedSignal.cir) developed and fully validated.

• Clear demonstration of correct data flow from transmitter to receiver:
  100% bit-exact transmission verified for alternating patterns (0x55), 
  asymmetric payloads (0xA5), and multi-byte sequential strings ("ESIM").

• Proper verification of timing, synchronization, and errors:
  - Timing: Baud rate calibrated to 62.5 kBaud (T_bit = 16.0 us) with 1 MHz clock.
  - Synchronization: Verified falling-edge start-bit detection, start-bit glitch 
    rejection, and zero-drift mid-bit eye-center sampling.
  - Error Detection: Single-bit parity error and framing error (corrupted stop bit) 
    injected and successfully flagged by the receiver hardware.
